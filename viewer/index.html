    What this shows

    • Sorted list: insert walks the list, so the work grows with N.
    • Binary heap: every operation is O(log N), in the worst case too.
    • Fibonacci heap: insert is O(1) and work is postponed to ExtractMin, so it does the fewest comparisons. It allocates a node per insert and follows pointers, so it can still be slower in real time.
    • The worst tick is t = 0, when all N tasks are released at once.
